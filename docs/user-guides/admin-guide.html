1管理员权限

管理员 = 运营全部功能 + 「管理面板」分组 + 若干仅管理员的子页。

用管理员账号登录后,左侧除「运营工作区」外多出 管理面板 分组:运营账户、爬虫 Job、爬虫机、csvType 管理、飞书外发、审计日志、运行错误。此外,舆情监控与 AI 助手的「模型设置 / 知识库 / 用量统计」等子页也仅对管理员开放,采集任务的「新建 Job」按钮也仅管理员可见。

权限边界:普通运营看不到管理面板;涉及触发/删除/重跑舆情、改模型、维护知识库、改 Job 模板、管账户/机器等敏感动作均限管理员。

2运营账户

/operator/admin/operators · 创建与维护后台账户(仅 OPERATOR / ADMIN;创作者账号在「创作者管理」处理)。

列表

  • 筛选:角色(运营 / 管理员)、状态(启用 / 停用)、用户名搜索。
  • 列:用户名 · 邮箱 · 角色徽标 · 状态 · 创建时间。右上「新建账户」。
  1. 新建账户填用户名、初始密码、角色。密码以 argon2 哈希存储。
  2. 编辑调整资料/角色或重置密码。
  3. 启停停用后该账户无法登录。
最小授权原则:日常审核/运营给 OPERATOR;只有需要管机器、账户、外发的人才给 ADMIN。

3爬虫 Job

/operator/admin/jobs · Jenkins 风格采集模板。Job 是模板,每次执行叫 Task。

3.1 列表

筛选:全部 / 启用中 / 已停用。右上「新建 Job」。每行可切换启停,点进查看/编辑。

3.2 新建 / 编辑 Job 表单

区块字段
基础信息Job 名称*、绑定爬虫机*(下拉,已停用机器不可选)、描述。
代码 & 执行仓库类型(Git / SVN)、仓库地址*、分支(Git)、工作目录(相对仓库根)、超时(1–720 分钟)、命令模板*。
参数定义定义运行参数;触发时 UI 按类型(日期 / 文本 / 数值 / 枚举 / EXCEL)自动生成表单。
产物清单脚本跑完后 agent 按此收集产物;带 csvType 的上传入库,不带的留在爬虫机本地。
调度Cron 表达式(可选)+ 两个开关(见下)。

命令模板

用 {{参数名}} 引用参数,例:python run.py --start={{startDate}} --end={{endDate}}。支持中文参数名(如 {{开始时间}})。

两个开关(务必分清)

开关语义
定时启用(enabled)仅控制 cron 自动触发;关掉后不再定时跑,但手动触发仍可。
任务启用(active)整体总开关;停用后任何方式都不可触发(含手动 / rerun)。

产物入库规则

  • 产物清单支持 glob(* ? [])与 optional 标志。
  • csvType 非空 → 入 data/raw/<csvType>/ 并跑 parser 解析入明细表。
  • csvType 空 → 入 _uncategorized/,仅留底可下载、不解析。
失败不自动重试;手动重跑克隆出新 Task(保留原记录)。每台爬虫机并发=1。改模板属高危操作,不放开给运营。

4爬虫机(Agent)

/operator/admin/agents · 采集端机器。拉模型:机器主动轮询中台领任务、回传 CSV,中台从不主动连机器。

列表

  • 筛选:启用 / 停用 + 名称搜索。
  • 列:名称 · 状态 · 最近心跳时间 · 最近来源 IP · 创建人 · 关联任务/Job 数。
  • 状态为「启用」但超过 10 分钟无心跳会红色高亮标 OFFLINE。右上「新建机器」。
  1. 新建机器创建后获得 token;爬虫端配置该 token 后即可上线轮询。
  2. 重置 token在机器详情可重置(旧 token 失效)。
  3. 绑定任务通过 Job 显式绑定到某台机器执行。

取消机制

任务执行期间 agent 每 5 秒空 POST /log;若中台返回 4xx(表示已取消),agent 立即 kill 子进程。

部署形态:中台在阿里云,爬虫机在本地 Windows 内网,仅单向出站访问中台——无需给爬虫机开公网入站。

5csvType 管理

/operator/admin/csv-types · 维护 CSV 类型清单。csvType 决定产物入哪张明细表、用哪个解析器。

  • 每种 csvType 对应代码内的一个解析器,例:douyin_video_detail→视频明细、live_detail→直播明细、anchor_roster→主播名单。
  • 在此登记/停用 csvType,供 Job 产物清单与手动导入选择。
CSV→表的映射逻辑写在代码里。真正的新格式需开发补一个 parser;本页管理的是可选清单与元数据,不是映射本身。

6飞书外发

/operator/admin/feishu · 通过飞书群自定义机器人 webhook 外发通知/日报。

新增 webhook

填:名称* · webhook 地址* · 加签密钥(可选)· 是否发日报。提交后地址与密钥只保存不回显,列表仅显示打码串。

每个 webhook 的操作

操作作用
启用开关控制该 webhook 是否生效。
日报开关是否纳入运营日报定时推送。
测试发一条测试消息验证连通与加签。
发日报立即手动推送一次日报。
编辑 / 删除修改名称/地址/密钥/开关;删除该配置。
webhook 地址与加签密钥属敏感信息,妥善保管、不要外泄。相关功能上线前若报错,需先执行 pnpm db:generate。

7审计日志

/operator/admin/audit-logs · 关键动作留痕,用于追责与复盘。

筛选与分页

  • 筛选(URL 同步):操作人(用户名模糊)· 动作 · 目标类型 · 时间段。
  • 数据范围硬底近 60 天——用户填的开始时间只能在此窗口内再收窄,不能往前翻。
  • 每页条数可选 25 / 50 / 100 / 200;按时间倒序。
  • 每行「详情」点开 Dialog 显示完整 details JSON。

记录的动作

类别动作
采集任务task.trigger / cancel / requeue / rerun / priority
数据导入data.import(主播 / 视频 / 直播 / 易闪)
激励incentive.compute / incentive.adjust
舆情opinion.trigger / rerun / delete / settings.update

每条含:操作人 ID + 用户名快照、目标类型/ID、details JSON、时间。敏感明文(如 apiKey)永不入日志。

8运行错误

/operator/admin/logs · 系统运行错误(ErrorLog)查询,用于排障。

  • 只读列出高价值 error/fatal 日志(后端错误经隔离队列写入,前端错误也上报),按发生时间倒序。
  • 筛选:级别 · 模块(模糊)· requestId · traceId · taskId · fingerprint · 时间段;每页 25/50/100/200。
  • 数据范围硬底近 90 天;不提供未脱敏原始日志下载。每行可点开详情。
若页面提示「运行错误表尚未就绪」:需停 dev、执行 pnpm db:migrate 生成 error_log 表并重新生成 Prisma client,再设 LOG_ERROR_DB_ENABLED=true。

9模型设置(舆情 / AI 助手)

仅管理员可配置的 LLM 相关设置,入口在对应模块的二级菜单。

入口作用
舆情 · 模型设置 /operator/opinion/settings配置分析服务所用 LLM(单例),apiKey 以 AES-256-GCM 加密存储。
AI 助手 · 模型设置 /operator/assistant/settings配置对话助手模型。
AI 助手 · 知识库 /operator/assistant/knowledge维护 RAG 知识条目。
AI 助手 · 用量统计 /operator/assistant/usage查看调用量 / 成本。
舆情报告由独立分析服务(Docker 容器)生成,中台仅代理调用。若报告触发失败,先在此确认模型配置与分析服务连通性。

10关键运行约束

排障与配置时需知的技术边界。

活动状态与激励

  • 活动状态在读取时自动流转:草稿→(发布时间到点)进行中→(截止到点)已结束。
  • 隐藏(hidden)的作品不参与任何统计与激励;只有审核通过的投稿计入激励。

数据分层

原始层(留底)→ 明细层(upsert 只留最新)→ 每日汇总层(历史趋势)。

时区

数据库强制 timezone='UTC';前端锁 Asia/Shanghai 渲染;审计/错误日志的时间筛选把输入显式当作北京时间(+08:00)。

任务日志查看模式

Task 日志页默认折叠,展开只渲染尾 100 行;支持 ?lines=N / ?tail=N / ?offset=N / ?download=1 四种模式。

改数据模型的正确姿势:先改 schema.prisma → migrate → 写代码,不手写 SQL DDL;提交前跑 pnpm typecheck && pnpm test。

11环境变量与命令

参数注入与命令渲染

  • 参数名允许中文/字母/数字/下划线;agent 把参数值全部注入子进程环境变量,脚本用 os.environ["开始时间"] 读取。
  • EXCEL 类型参数:运营端上传 .xlsx/.csv,前端解析为数组后经 env 字符串(JSON)传给脚本。

舆情 / 分析服务环境变量

ANALYSIS_BASE_URL       # 分析服务地址(dev 默认 http://127.0.0.1:8000)
ANALYSIS_SHARED_SECRET  # Bearer token,与分析服务同源
OPINION_AES_KEY         # 32 字节 base64,加密 apiKey 用

上述缺失时只 warn 不阻塞其他功能,首次触发舆情接口时才懒失败。

分析服务本地启动

cd F:\Kaifa\data-hub\services\slg
docker compose up -d   # 先在 shell 或该目录 .env 设 ANALYSIS_SHARED_SECRET

常用命令

pnpm dev / build
pnpm db:migrate / db:generate / db:studio / db:seed
pnpm typecheck / lint / test / test:e2e
