1登录与账号

所有角色共用一个登录入口,系统按账号角色自动分流。创作者账号需注册并经运营审核后方可使用。

1.1 着陆页

打开系统首页(/login)是一张产品着陆页。你需要用到的只有右上角两个入口:

元素作用
右上「登录」弹出登录/注册浮层,并停在「登录」标签。
右上「Get started」/ 页面中间「Get started」弹出同一浮层,停在「注册」标签。

浮层可按 Esc 或点浮层外部关闭。浮层内顶部有「登录 / 注册」两个切换标签。

1.2 注册账号

在浮层切到「注册」标签,依次填写:

字段说明 / 要求
昵称对外展示的名字,必填。
用户名登录用,3–32 字符,必填,唯一。
邮箱用于找回/通知,建议填写。
密码输入时下方有强度条(较弱 / 一般 / 良好 / 强),右侧眼睛图标可切换明文显示。
确认密码两次不一致会即时红字提示。
同意条款必须勾选「服务条款与隐私政策」复选框,否则「创建账号」按钮不可点。
注册后不会立即登录。提交成功后会显示绿色提示「账号已提交运营审核,审核通过后即可登录」,并给出「去登录页等待 →」链接。请等待运营审核。

1.3 登录

  1. 输入用户名与密码密码框右侧眼睛图标可切换显示明文。
  2. 记住此设备默认勾选,便于下次免密。「忘记密码?」暂未开放。
  3. 点「登录」成功后创作者自动进入 /dashboard 概览页。

1.4 账号三种状态

状态能做什么
待审核刚注册,尚不能登录使用,等待运营通过。
已启用正常账号,可报名、投稿。
已停用被运营停用,无法登录/投稿,需联系运营。

2界面导览

登录后是左右布局:左侧固定导航栏,右侧是当前页面内容。以下元素在每个页面都在。

2.1 左侧导航栏

顶部品牌块显示「GameOps · 创作者工作台」。下面是四个主菜单,点击即跳转:

菜单去向二级项(展开)
概览数据首页—
活动活动列表已参加 / 进行中 / 已结束
我的投稿投稿管理全部投稿 / 待审核 / 已通过 / 未通过
创作灵感资源库—

导航栏可折叠成图标条(点栏边缘的折叠条 / Rail),窄屏时自动收起。

2.2 左下角账户菜单

左下角是你的头像 + 昵称 + @用户名,点击展开下拉菜单,包含:

菜单项作用
账户设置进入个人资料与安全设置页(见第 11 节)。
通知进入通知页(见第 10 节)。
深色模式 / 浅色模式一键切换整站明暗主题,随点随变。
退出登录结束会话并返回登录页。
大部分列表页顶部有标题与说明文字;活动/投稿详情页左上角有「返回」链接回到上一层。

3概览页

/dashboard · 登录后的首页,一屏看清你的报名与投稿状态。

顶部四张统计卡

卡片含义
已报名活动你累计报名过的活动数。
待审核已提交、等待运营审核的投稿数。
已通过审核通过的投稿数。
未通过被驳回的投稿数。

我的预估激励(有激励时才显示)

大字显示所有活动的预估激励总额(¥),下方列出金额最高的前 5 个活动,点活动名进入该活动详情。若某条被运营调过,会带「已调整」标记。右上「查看活动 →」跳到活动列表。金额以最终结算为准。

下半区:最近投稿 + 进行中的活动

  • 最近投稿(左)——最近 8 条投稿,每行显示标题、平台、所属活动、时间和状态徽标。右上「查看全部 →」进入我的投稿。
  • 进行中的活动(右)——平台当前进行中的活动,已报名的打「已报名」绿标,显示起止时间与报名/投稿人数。

4活动列表

/dashboard/activities · 浏览可参与和已结束的活动,封面卡片按月份分组。

筛选条(页面顶部)

控件作用
搜索框按活动名称模糊搜索。
日期范围(起 / 止)按活动开始时间筛选落在区间内的活动。
状态(来自左侧二级菜单)已参加(只看报名过的)/ 进行中 / 已结束。默认展示「进行中 + 已结束」。

活动卡片

每张卡片是一个活动,元素包括:封面图、左上角状态徽标(进行中/已结束/草稿)、若已报名则并排「已报名」绿标、活动名、两行描述、底部起止日期与报名/投稿人数。点卡片任意位置进入活动详情。

卡片按「年 月」分段,每段右上角显示该月活动数量,便于回看往期活动。

5活动详情与报名

/dashboard/activities/[id] · 活动的完整信息、报名、投稿都在这一页。

页面结构(从上到下)

  1. 返回活动列表——左上角链接。
  2. 封面大图卡——封面 + 状态徽标 + 是否已报名 + 活动名 + 起止时间 + 报名/投稿总数;下方是活动描述。
  3. 参与活动卡——见下方报名说明。
  4. 我的预估激励卡——运营重算后才出现,含金额与「规则贡献明细」(见第 8 节)。
  5. 向本活动投稿(左下)+ 我的投稿·本活动(右下)。

报名

  1. 确认活动进行中只有状态为 进行中 时,「参与活动」卡右侧才有报名按钮。
  2. 点击报名成功后卡片显示报名时间,并出现「已报名」标记。
  3. 报名是投稿的前提未报名时,下方投稿区会提示「请先报名该活动后再投稿」。
活动到达发布时间会自动从「草稿」变「进行中」,到截止时间自动变「已结束」。已结束的活动不可报名、不可投稿。

我的投稿(本活动)

右下卡片列出你在本活动下的全部投稿:标题(可点开原链接)、平台、提交时间、审核备注(若有)、状态徽标。

6投稿

在已报名的进行中活动详情页填写投稿表单。字段如下:

字段说明
挂载活动在活动详情页投稿时已固定为本活动,不出现此项;若从通用入口投稿,可下拉选择活动或「不挂活动」。
标题作品标题。
链接作品的公开访问地址,以 https:// 开头。
平台下拉四选:抖音 / 哔哩哔哩 / 小红书 / 快手。
  1. 填写并点「提交投稿」按钮在提交中会显示「提交中…」。
  2. 成功提示成功后显示绿色「已提交,等待审核」,表单标题/链接清空,可继续投下一篇。
  3. 失败提示字段有误会在按钮上方红字说明原因,据此修改重试。
链接必须真实可访问、指向本人作品。运营会打开链接核验标题与内容;平台已删除或取不到标题的作品在统计中会被标记为「已删除隐藏」,不计入激励。

7我的投稿

/dashboard/submissions · 集中管理全部作品,按所属活动分组、按月份分段。

筛选

入口 / 控件行为
全部投稿(默认)提供搜索框(按标题或活动名)+ 日期范围筛选。
待审核 / 已通过 / 未通过来自左侧二级菜单,固定只看本月,不显示日期控件。

分组卡片

投稿按活动折叠成卡片(未挂活动的归为「未挂活动的独立投稿」)。卡片标题栏显示活动名、活动状态徽标、该组稿件数,以及三态计数徽标(待审 / 已通过 / 未通过);右侧「查看活动」跳转。点标题栏展开,内部逐条列出:

  • 作品标题(点击打开原链接)、平台 + 提交时间;
  • 若运营写了「审核备注」,显示在下方——被驳回时按备注修改后可重新投稿;
  • 行尾是该稿件的状态徽标。

8预估激励

激励是活动奖励的量化金额,由运营配置规则、系统自动计算,可在概览页与活动详情页查看。

规则贡献明细

在活动详情的激励卡内,会逐条列出每个规则块对总额的贡献,例如 #1 分档 +¥50.00、#2 每投稿 +¥20.00。这让你清楚金额由哪些部分构成。

字段含义

字段说明
系统预估引擎按运营配置自动算出的金额。
已调整运营做过人工调整,页面会同时展示调整后金额、原系统预估值,以及「调整说明」。
更新于该激励最近一次被重算的时间。
预估 ≠ 最终结算。金额会随运营多次重算/调整而变化;只有审核通过的投稿参与计算,被隐藏/删除的作品不计入。一切以最终结算为准。

9创作灵感

从登录页进入 /inspirations 即可浏览公开素材。已登录创作者也可在工作台的 /dashboard/inspirations 使用同一资源库。

先选武将立绘、故事素材等主题，再按类型、关键词或标签缩小范围。列表每页 24 项。打开资源可复制分享链接，收件人可直接查看已发布内容。

多文件资源可用预览两侧箭头切换，也可展开文件清单逐个选择。双击图片可放大，视频可全屏。腾讯文档和飞书链接沿用来源平台的访问权限。

选择单个附件下载原文件，或点「下载全部」获取 ZIP。故事素材包包含站内图片、视频及已有的故事正文；其他资源包中的外链以链接文本提供。

10通知

/dashboard/notifications · 由左下角账户菜单进入。

规划用于展示审核结果、活动节点、激励发放等通知。当前为占位页,显示「暂无通知」。审核结果目前请在「我的投稿」中查看状态与备注。

11账户设置

/dashboard/account · 维护个人资料与账户安全。资料越准确,运营越容易核验你的投稿归属。

资料概览卡

顶部展示当前头像、昵称、@用户名 与邮箱。

编辑资料

项说明
头像从预设头像网格中点选一个,选中项右下角打勾;下方「清空头像」可移除。
昵称对外展示名。
团号组织内部编号。
易闪 ID形如 YS123456。
抖音昵称 / 抖音号 / 抖音主页链接你的抖音账号信息,链接以 https:// 开头。

底部「保存」提交,「重置」放弃改动恢复原值;保存成功显示「已保存」。

账户安全

  • 邮箱——修改绑定邮箱。
  • 密码——修改登录密码,需要先输入当前密码。

B常见问题

看不到投稿表单?

需同时满足:活动「进行中」+ 你已报名 + 账号「已启用」。任一不满足都不显示。

投稿被判「未通过」怎么办?

在「我的投稿」或活动详情里查看该稿件的「审核备注」,按说明修改后重新投稿。

激励金额一直在变?

正常。运营会随活动进展多次重算并可能人工调整,卡片上的「更新于」标示最近时间。以最终结算为准。

注册后登录不了?

账号可能仍「待审核」或被「停用」。请联系运营确认状态。

怎么切换深浅色 / 退出登录?

都在左下角头像菜单里。
