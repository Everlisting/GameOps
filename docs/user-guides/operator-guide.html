1登录与角色

与创作者共用登录入口。用运营/管理员账号登录后,自动进入 /operator/dashboard。

  • 角色层级:管理员（ADMIN）⊃ 运营（OPERATOR）⊃ 审核员（REVIEWER）。审核员登录后进入 /operator/submissions，仅处理分配给自己的稿件。管理员比运营多一整组「管理面板」。
  • 账号来源:审核、运营和管理员账号由管理员在「运营账户管理」中创建,不能自行注册(注册入口只产出创作者账号)。

2界面导览

左侧为 GameOps 运营中台导航，右侧显示当前工作区。

2.1 左侧导航分组

运营工作区（运营和管理员可见）:概览、BI 大屏、项目数据、活动管理、舆情监控、稿件管理、创作者管理、创作灵感、AI 助手、采集任务、采集数据。
管理面板 仅管理员:运营账户、爬虫 Job、爬虫机、csvType 管理、飞书外发、审计日志、运行错误。

「活动管理」下可选专题活动或征稿活动。审核员的「审核工作区」只展示稿件入口。

2.2 左下角账户菜单

显示你的用户名和角色。下拉含：账户设置、深色/浅色模式切换、退出登录。

带日期时间的筛选统一用日期时间选择器;下拉统一用 Select 组件;URL 会同步筛选条件,便于分享带筛选的链接。

3概览

/operator/dashboard 分四块展示。项目数据默认统计北京时间本月，可切换最近 12 个月；视频播放量为当月所发作品的当前累计值，直播按月汇总，主播人数取全库名单。

稿件区显示全库有效视频的审核进度、未分配数和最近两个审核中周期。活动区列出最多四个进行中的专题或征稿活动，按截止日从近到远排列。舆情区展示任务数和最近三项任务。

月份只影响项目数据。点击刷新可重新读取四块数据，舆情服务超时时其他三块仍可查看。

4BI 大屏

/operator/bi 按北京时间的作品发布日期筛选，排除隐藏及无发布日期的视频。默认范围为最近一个有作品的日期向前 30 天，止日最晚为昨天，可选区间最长 366 天。页面支持手动刷新和全屏。

播放量表示入选作品当前累计播放量。要看增长，请看「每日可比播放变化」，它仅比较相邻两天均有快照的同一作品；缺数据的日期留空。审核合格率的分母为已审核作品，审核进度的分母为全部入选作品。

可查看达人与作品排行、作品分层和平台分布。底部活动、审核周期及舆情展示当前状态。

5项目数据

三张明细表:主播 / 视频 / 直播。均支持手动导入(补录、回填)与导出,爬虫上报复用同一套解析器。视频和直播默认显示本月，可按业务日期查往月；主播名单单独按入会日期筛选;顶部有统计卡,支持排序与分页(每页条数可选)。

5.1 主播数据 /operator/data/streamers

以主播名单为基表，按平台和 UID 汇总视频与直播指标。本月没有作品的主播仍在名单内。

列

来源字段
名单(导入)平台 · UID · 昵称 · 抖音号 · 入会时间 · 团号 · 运营经纪人 · 招募经纪人 · 粉丝量
视频聚合作品数 · 作品播放量 · 作品推荐播放量 · 涨粉
直播聚合直播天数 · 直播时长 · ACU · 曝光人数/次数 · 进直播间人数/次数 · 人均观看时长

顶部统计

名单主播数 / 总作品数 / 总作品播放量 / 总作品推荐播放量(随名单筛选变化)。

操作与筛选

  • 导入(右上)——上传名单表,识别列:主播平台 / UID(必需)/ 昵称 / 抖音号 / 入会时间 / 团号 / 运营经纪人 / 招募经纪人 / 粉丝量;按(平台, UID)去重更新,只写身份字段、缺列不覆盖。
  • 导出——导出当前筛选结果。
  • 搜索、团号和入会时间筛选主播名单。视频与直播按平台和 UID 汇总，默认统计北京时间本月 1 日至今天，期间没有作品的主播仍保留。
  • 表头可点击排序。
源表无「直播场次」列,故本页无此指标;被隐藏/删除的作品不计入统计。

5.2 视频数据 /operator/data/videos

列

平台 · 视频ID · 链接 · 标题 · 发布时间 · 创作者UID/昵称/抖音号 · 播放量 · 推荐播放量 · 点赞 · 评论 · 分享 · 涨粉 · 运营经纪人 · 招募经纪人 · 备注(团号)· 隐藏状态。

顶部统计

作品条数 / 作品人数(去重 UID)/ 总播放量 / 总推荐播放量。

操作

  • 导入视频明细——上传 CSV/Excel(固定类型 douyin_video_detail),用于补录/回填。
  • 导出、发布日期筛选(默认本月)、团号 / 搜索、表头排序。
  • 状态筛选:正常 / 已删除隐藏 / 全部。
达人删除/隐藏机制:每次导入按 CSV 的「发布日期窗口」比对——窗口内在库但本次缺失、或只有链接无标题的作品判为 已删除隐藏;窗口外不动;重新出现自动恢复。隐藏行不参与任何统计与激励,仅留存展示。

5.3 直播数据 /operator/data/live

数据源 LiveStat,主播 × 自然日一行,来自「所有主播画像表」。

列

平台 · UID · 日期 · 昵称 · 抖音号 · 音浪 · 有效开播时长 · 曝光人数/次数 · 进直播间人数/次数 · 进直播间转化率 · 人均观看时长 · 打赏人数/次数 · 新增粉丝 · ACU · 备注(团号)。

顶部统计

记录数 / 主播数 / 总开播时长 / 总曝光人数。

导入规则

  • 只入「有效开播时长 > 0」的行(空开播行跳过并计数);排除游戏流水两列不入库;日期按 UTC 存日期型。
  • 操作:导入 / 导出 / 日期筛选(默认本月)/ 搜索 / 团号 / 排序。
所有导入都会写审计(data.import),可在管理面板「审计日志」按操作人追溯。

6活动管理

征稿活动接收报名和投稿；专题活动从视频库匹配作品。两者各自计算奖励。

专题活动 /operator/special-activities

设置日期、标题关键词、达人 UID 或作品名单，配置奖池并试算。在「稿件明细」查看命中与排除原因。仅审核合格的稿件参与计奖；若有待审稿件，先完成审核再刷新预估。满足截止及数据条件后，确认结算会冻结本次结果。

6.1 征稿活动列表 /operator/activities

  • 点击右上角「新建征稿活动」进入创建表单。
  • 筛选——搜索(活动名)+ 日期范围;在列表中按状态筛选:全部 / 进行中 / 草稿 / 已结束。
  • 卡片——封面 + 状态徽标 + 活动名 + 描述 + 起止 + 报名/投稿数;草稿若设了定时发布,右上角有「定时发布」小标。点卡进详情。

6.2 新建 / 编辑活动

新建的活动默认是草稿。表单分块:

区块字段 / 说明
基础信息活动名称*(≤120 字)、活动描述(≤2000 字)、封面图、开始时间*、结束时间*。
封面图点击上传 PNG/JPG/WebP/GIF,≤5 MB,建议 16:9;可更换或移除。
激励规则可折叠区,叠加最多 10 条规则(见 7.1);标题显示「已配 N 条」。
定时发布(仅草稿)设定发布时间,到点自动转「进行中」;留空则需手动上线。

编辑权限随状态变化

状态可编辑性
草稿全部可改,含定时发布。底部按钮「创建草稿 / 保存」。
进行中默认锁定。右上角横幅「点击解锁」→ 二级确认弹窗「确认解锁」后才能改。可「重新锁定」。
已结束永久只读,基础信息与规则都不可改,只有「返回」。

6.3 活动详情

顶部有活动信息与状态;下方是活动表单(按上面权限规则)+ 激励结算区(见第 7 节)。

7征稿活动激励

激励引擎按你配置的规则,为「报名 ∪ 投稿」的候选人计算金额。

7.1 七类规则块

每条规则可选挂 cap(封顶金额)与 cpmCap(每千播放封顶;创作者 views=0 时不生效)。

规则用途
TIER 分档按某指标落入档位给不同金额。
FORMULA 公式按公式(如播放量×系数)计算。
SHARE_POOL 分池固定奖池按贡献占比分配。
RANK 排名按名次给奖。
PER_SUBMISSION 计件每篇合格投稿固定金额。
ACTIVITY_THRESHOLD 门槛达到活跃门槛才发放。
BASE_PLUS_STEP 底+步进保底 + 按量阶梯递增。

7.2 重算与人工调整

  1. 全活动重算在活动结算区触发,引擎重算所有候选人金额并落库,创作者端同步可见。审计 incentive.compute。
  2. 人工调整单条对个别创作者在系统预估上手改金额并填「调整说明」,原预估值保留、创作者端显示「已调整」。审计 incentive.adjust。
只有审核通过的投稿参与激励;被隐藏/删除的作品一律排除。

8稿件审核

从「全部稿件」进入 /operator/submissions。周期按北京时间的作品发布时间统计视频库，可覆盖未参加征稿活动的作品。

  1. 创建与分配（运营、管理员）　创建周期后点「查看详情」，从有效、待审且未分配的视频中，按组均分或按人指定数量。先预览再确认；可用数量变化时重新预览。重叠周期内同一作品只分配一次，已有分配的周期仅能改名称和状态。
  2. 进入审核　审核员点周期卡「前往审核」，仅看到本人分配的作品。运营和管理员可在周期详情点「进入稿件审核」。在 /operator/submissions/review 选择审核活动会同步日期范围。
  3. 逐条保存　点标题旁的审核按钮打开指定作品，或点「开始审核」从当前范围内最早的待审作品开始。预览视频，选择合格或不合格，并选到该分支最后一个可用标签（最多三级）。可填写备注，再选择保存并关闭或「保存并审核下一条」。
  4. 核对记录　运营和管理员可在列表右侧查看审核人、时间、结果、标签和备注。周期标记为冻结后仍按最新视频数据统计。易闪结果导入属于征稿记录，由运营或管理员操作。

9创作者管理

/operator/creators · 审核注册、维护账号与平台账号信息。

筛选与列

  • 搜索命中 抖音 UID / 抖音昵称 / 抖音号 / 易闪 ID;团号独立筛选;左侧状态菜单:全部 / 待审核 / 已启用 / 已停用;支持分页。
  • 若有待审核,右上会出现「待审核 N · 去审核」快捷入口。
  • 表格列:创作者(头像+昵称+@用户名)· 抖音UID · 抖音昵称 · 抖音号 · 易闪ID · 团号 · 等级 · 状态 · 报名数 · 投稿数 · 注册时间。点行进详情。
  1. 审核注册在「待审核」中核验资料后通过/拒绝。通过后账号变 已启用,方可投稿。
  2. 启用 / 停用在详情页切换;停用后该创作者无法登录/投稿。

10创作灵感

在 /operator/inspirations 创建或编辑资源，选择主题、类型和标签。保存为草稿后可继续编辑；发布后，游客即可通过 /inspirations 浏览和分享。

每项最多 30 个附件，可混合图片、视频、音频、文档和 ZIP。首项为主文件，可调整顺序或设为主文件。上传失败时重试或移除失败项，再保存。单文件上限为封面 5 MB、图片 50 MB、视频 500 MB、音频 100 MB、文档和 ZIP 1 GB。

11舆情监控

三份报告:私域 / 公域 / 对比。运营可查看列表与报告;触发 / 删除 / 重跑与模型设置仅管理员。

页面内容
私域舆情基于聊天记录导出的社群深度报告。
公域舆情抖音 / B 站 / 小红书 三平台评论合并后的深度报告。
对比报告读取已完成的私域 + 公域固化结果,做叠加解读。
模型设置 仅管理员LLM 配置(apiKey 加密存储)。

页面元素

  • 顶部统计卡(各状态任务数)+ 任务表格(自动轮询刷新状态)+ 分页 / 每页条数。
  • 管理员右上有「触发」按钮(私域/公域为上传文件对话框,对比为选择已完成报告对话框)。
  • 未配置模型时显示黄色提示条(仅管理员可见并前往设置)。
  • 任务完成后,点进可经鉴权在新页面打开 HTML 报告(非 iframe)。产物由后台每 10 秒从分析服务拉回。
若长时间无结果:可能分析服务未启动或未配置模型,请联系管理员检查「模型设置」并重新触发。

13采集任务

/operator/tasks · Jenkins 风格的三层视图。

层级内容
① Job 列表(本页)每行一个采集模板:名称、绑定爬虫机、cron(中文描述)、最近运行状态+时间、总执行次数。筛选:全部 / 启用中 / 已停用 + 搜索。
② Job 详情点 Job 名进入:触发表单(按参数定义生成)+ 最近执行列表。
③ 单次执行点某次执行:参数、耗时、折叠日志(展开只渲染尾 100 行,可下载完整日志)。
  • 手动触发随时可用;失败不自动重试,重跑会克隆出一个新执行。每台爬虫机并发=1。
  • 「新建 Job」按钮仅管理员可见(改模板属高危操作)。
  • 关键动作(触发/取消/重排/重跑/改优先级)都写审计。

14采集数据

/operator/datasets · 爬虫上传的原始 CSV 留底,可下载与重跑解析。

  • 列表(最近 200 条):csvType、文件名/大小、行数、解析状态(已解析/解析错误)、来源任务(Job + 执行序号 + 触发人)、时间。
  • 每行有下载按钮(需登录)。可按 csvType 过滤。
  • 未分类产物入 _uncategorized/,仅留底可下载、不解析。

15账户设置

/operator/account · 由左下角账户菜单进入。

  • 可修改显示用户名。固定账号名称用于登录与审计。顶部卡片显示邮箱、角色徽标、账号状态、创建/更新时间。
  • 账户安全:修改邮箱;修改登录密码(需当前密码)。
  • 账号的角色与状态由管理员维护,本页不可自改。
