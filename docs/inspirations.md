# 创作灵感与公开创作库

公开入口 `/inspirations` 位于创作者鉴权布局之外，游客及任意已登录角色都可以浏览。登录页导航提供入口；已登录访客可从公开页进入自己的工作台。原 `/dashboard/inspirations` 继续要求创作者身份，复用相同浏览组件，并隐藏工作台右侧概览栏。

内容主题参考本地最新版 `F:/Kaifa/LvtuCreatorArchive/app/lib/assets.ts`：武将立绘、游戏素材、三视图库、百大作者、率土CG、率土cos、故事素材、武将设定、联动素材。旧 Sites 版本的七类定义不再作为依据。主题复用同名 `tags`，运营表单提供独立主题选择；已有标签和未分类内容保留，旧主题标签仍可通过普通标签筛选；不改写历史数据。主题与资源类型可组合筛选，主题计数与类型计数均为全部已发布资源数量，不随其他条件变化。

资源类型沿用教程/素材模型；`MaterialCategory` 增加 AUDIO（音效配乐）与 TEMPLATE（模板文件），其余历史枚举保持兼容。部署前执行 `pnpm exec prisma migrate deploy` 与 `pnpm db:generate`。迁移由 Prisma schema 差异生成：`20261119040000_inspiration_audio_template` 新增枚举，`20261119053000_inspiration_files` 新增 `Inspiration.files` JSONB 清单；不改动知识库向量索引。

浏览服务 `lib/inspirations.ts` 对列表、计数、标签和分享详情分别强制 `published=true`，不返回创建者账户信息。每页24条，数据库搜索标题/简介；按创建时间和ID稳定排序。URL保存主题、类型、关键词、标签、排序和页码。筛选请求带 `keepFilters=1`，支持刷新、前进和后退。分享链接为 `/inspirations?item=<id>`，草稿或删除资源不展示详情。

创作者页面保留首屏介绍、带图标及说明的九类主题卡片、左侧资源类型导航与右侧搜索/素材区，维持原有留白和分区层次。素材卡片根据实际内容区宽度自动填充列数（桌面每张至少210px，当前1440px视口约5列），不强制6列；手机为2列。卡片继续展示完整构图封面、单行标题、类型及月/日日期，简介与标签留在详情中。后续调整素材密度时，不改动整体页面布局。

详情弹窗限制在92dvh内，隐藏可见滚动条，保留长内容滚动及键盘可达性。武将设定支持滑动、鼠标拖动和左右键；图片两侧为仅图标的圆形箭头，到边界禁用，下方保留滑动提示。故事正文与图片/视频在桌面端并排、手机端上下展示。标题区提供下载资源、复制正文和分享。双击图片或使用放大按钮可在页内查看大图，视频预览提供全屏按钮。直链视频、抖音播放器、图片与直链音频按类型预览。腾讯文档、飞书文档和知识库的标准 HTTPS 分享链接使用受限 iframe 预览，并提供平台打开入口，访问仍遵循平台权限。已有飞书主链接的教程追加获准公开的 PDF 附件后，弹窗默认预览 PDF，仍可从附件列表切换至飞书预览。站内 PDF 使用浏览器的 PDF 查看器。

多文件素材在 `Inspiration.files` 中保存有序附件清单（id/name/url/kind/mime/size），首项为主文件并同步旧url；单个素材最多30个文件，支持图片、视频、音频、PDF、TXT、Markdown与ZIP混合。旧记录无需回填，读取时将url兼容为单文件。运营表单可多选、追加、修改显示名、上移/下移、设置主文件、移除；逐个流式上传，失败项可以重试或移除，未处理失败项及上传期间禁止保存。分类不限制附件格式，封面仍独立上传。创作者卡片显示文件数量。多文件详情可用预览两侧的图标按顺序切换文件，预览下方的文件清单默认折叠，展开可选择预览或逐个下载。标题区的「下载全部」使用 `?all=1` 流式打包，ZIP 以素材名称命名。站内附件保留原始字节，同名条目加序号。故事素材的 ZIP 仅包含站内图片、视频与有正文时生成的 `故事正文.txt`，单张图片或单个视频搭配正文也提供整包下载。其他素材的外链以链接文本列入包内。

公开下载接口 `GET /api/inspirations/[id]/download?file=<fileId>` 每次独立要求published=true，站内素材使用文件流与attachment响应返回未经转换的原文件，多文件下载名称沿用文件显示名和实际扩展名，旧单文件仍使用素材标题；fileId必须属于当前素材，省略时下载主文件；纯文本素材可下载为TXT。下载只允许素材目录中的文件，校验真实路径并拒绝跨目录与任意外链代理，外链资源仍从来源网站打开。

运营管理入口仍要求OPERATOR，提供数量概览、主题/类型/标签/发布状态筛选和24条分页列表。创建和编辑使用相同校验，PATCH合并现有记录后校验完整状态。发布后立即对游客可见，草稿只在后台出现。

原文件上传限制统一配置在 `lib/inspiration-upload.ts`：封面5MB、图片50MB、视频/视频教程500MB、音频100MB、文档/ZIP压缩包1GB（按1024换算）。前端显示限制并在上传前校验；服务端再次校验实际接收字节。音频支持MP3/WAV/OGG/M4A，模板支持ZIP，也可使用外链。文件原样保存，不压缩或重新编码。

新页面通过 `POST /api/operator/uploads/inspiration?kind=...` 直接上传二进制文件，Content-Type为文件MIME；服务端流式写入临时文件，超限、中断或空文件时删除临时文件，完成后改名并返回URL。兼容旧multipart请求（file+kind），旧路径仍需要formData解析。Nginx部署须同步 `docs/deploy-aliyun-guide.html` 的上传专用location：1025m请求上限（含multipart边界余量），关闭请求缓冲并调整超时；其他接口沿用原限制。

本次仅参考分类与浏览交互，不复制独立项目的上传数据、素材包/ZIP系统、共享密码鉴权或存储方式。GameOps 继续使用现有角色、Prisma数据、附件清单与资源链接。

本地验证：`pnpm typecheck`、`pnpm test`；`lib/inspirations.test.ts` 覆盖草稿隔离、分享详情范围、组合筛选、超过200条分页、非法链接、音频及模板必填资源。
