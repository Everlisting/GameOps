# BI 大屏设计与统计口径

更新：2026-11-18。页面：`/operator/bi`，仅运营和管理员可访问。

## 定位与布局

采用 ui-ux-pro-max 的 Data-Dense Dashboard 方向，沿用项目的 shadcn、字体和语义色。BI 侧重传播分析和内容结构；概览页继续承担运营工作入口。

- 六项核心指标：累计播放量、推荐播放量、发布作品、参与达人、高播放作品、审核合格率。
- 仅前三张核心指标卡（累计播放量、推荐播放量、发布作品）支持简短数值提示：悬停或键盘聚焦时显示完整数值与单位，不展示明细、说明或按钮。其他卡片不增加详情浮层或悬停强调效果。
- 中间：每日可比播放变化、每日发布作品两幅独立纵轴折线图，以及审核状态和进度。
- 下方：可切换的达人／作品 TOP 10，作品分层／达人分层／平台分布。排行支持手动滚动和键盘操作，不自动轮播。
- 运营协同：当前进行中的专题／征稿、审核周期状态、综合舆情任务状态；与历史发布时间筛选独立。
- 蓝色突出传播数据和操作，深青色表示发布量，审核待处理使用中性色，不合格使用警示色，并辅以文字。

## 数据范围

统一按北京时间的作品发布时间筛选 `VideoStat`，包含首尾日全天，排除隐藏作品及无发布时间作品。默认以最近一个有有效作品发布的日期为止日（最晚昨天），展示向前 30 天，历史数据默认范围在页首明确提示；无任何数据时使用截至昨天的最近 30 天。显式选择的日期不会因无数据而自动切换。可选 2000 年起的历史日期，一次最多 366 天。

播放量和推荐播放量均是所选作品的**当前累计值**，不是所选时间段内产生的播放增量。达人按平台和非空 UID 去重，未识别 UID 的作品仍计入作品总数。高播放作品指当前累计播放量 ≥ 10 万，与审核合格无关。审核合格率 = 合格数 ÷（合格数 + 不合格数）；无已审核作品显示「—」。审核进度 = 已审核数 ÷ 全部有效作品数。

每日发布量直接按视频库分日统计。播放变化使用 `DailyVideoStat` 同一视频在相邻自然日的累计值差，仅计入两天都有快照的视频。缺少连续快照时留空，真实零变化保留，负值保留为数据回调；提示中列出可比作品数和当日快照数。不同日期的样本覆盖可能不同，不能把缺失样本视为零增长。

平台分布及作品／达人分层全部使用同一视频库范围；包含零播放，分层边界互斥。达人榜入口携带平台、UID 与发布时间精确下钻，审核入口携带日期和状态。跨菜单下钻使用现有 `keepFilters` 约定。

## 运行与验证

数据随页面请求或手动刷新更新，不轮询；读取时间与采集时间分开表述。舆情服务在独立 Suspense 中读取，3.5 秒超时后显示不可用，不伪造零值。浏览器全屏作用于 document，保证日历 Popover 仍可操作；退出支持按钮及浏览器 Escape。

快照比较通过窗口函数 `LAG` 扫描所选日期及前一日，避免整张快照表自连接造成并行哈希的共享内存压力。无需数据库迁移或更改 Docker 配置。

回归测试覆盖北京时间边界、日期合法性、区间限制、缺失快照与真实零值／负值、比例和下钻参数；同时进行实际视频数据和浏览器验证。
